# 技术选型说明（MVP）

- **前端**：Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router、ECharts、vuedraggable  
- **后端**：Spring Boot 3、Java 17、Spring Security + JWT、JPA、MySQL  
- **AI**：Anthropic Claude API；`AIService` 统一重试；`SkillPrompts` 管理提示词  
- **接口文档**：SpringDoc OpenAPI（Swagger UI）  
- **部署**：Docker Compose + Nginx  

（Word 版：`技术选型说明.doc`。）
