# 金融科研 AI 辅助平台 — 需求说明书（MVP）

## 1. 背景与目标

为高校/金融机构科研人员提供中文云端工具，覆盖**选题 → 数据 → 写作 → 回修**闭环；强调上传数据加密存储、脱敏后调用大模型及审计留痕。

## 2. 功能范围

- 文献 PDF 上传与 AI 结构化解读  
- 选题生成、时效性选题、发表前景评估  
- EDC 表单设计、CSMAR/Akshare 字段映射、公开采集链接、模拟录入  
- CSV/Excel 上传、清洗报告、一键处理、描述统计、t 检验、OLS、简单图表  
- 论文初稿生成、段落四种改写、文献匹配、统计结果解读、JSON/XLSX 导出  
- 审稿意见解析、逐条修改建议、回复信、论文版本快照与回滚  
- 需求/选型类 Markdown 文档生成；脱敏试算与审计/脱敏日志查询  

## 3. 非功能需求

REST 统一 `{ code, data, message }`；JWT 鉴权；Docker 部署；Swagger 文档。生产环境需 HTTPS、密钥托管与正式数据源合同。
